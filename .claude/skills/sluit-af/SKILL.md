# Sluit af — FitTrick session wrap-up

Goal: the next Claude session must be able to continue on FitTrick from `CLAUDE.md` alone. Answer Patrick in Dutch.

## Steps

1. **Collect what happened this session**
   - `git status --short` and `git log --oneline` since the last date in the *Session log* of `CLAUDE.md`.
   - `git diff` (staged + unstaged) for uncommitted work.
   - What was decided or asked in this conversation (requirements, preferences, things Patrick tested or reported).

2. **Update `CLAUDE.md`** (edit in place, keep it compact and current — rewrite outdated statements instead of appending contradictions):
   - *Requirements*: new or changed wishes from Patrick.
   - *Architecture / Files / Sheet structure / Planner*: only when the code or sheets changed.
   - *Gotchas*: anything that cost time this session.
   - *Status*: current version, what works, what is unverified or broken.
   - *Backlog*: add new ideas/open items, remove finished ones.
   - *Session log*: one line `- **YYYY-MM-DD** — <what was done>` (absolute date).

3. **Check the Handleiding** (`docs/FitTrick Handleiding.docx`, generated by `docs/build_handleiding.py`):
   if this session changed user-visible behaviour, sheets, setup or the release procedure, update the generator text, rebuild the docx, and tell Patrick to re-upload it to his private Google Drive (replace the Google Doc: *Bestand → Importeren* or upload a new version). Bump the version/date on its title page.

4. **Sanity checks** (only if code changed): `node --test tests/`; if files in `app/` changed, confirm `VERSION` in `app/sw.js` was bumped.

5. **Report** to Patrick in a few lines: what was updated in CLAUDE.md, whether the Handleiding changed, test result, and what is **not committed / not pushed**. Then ask whether to commit and push (never push without his yes; commits use the noreply identity configured in the repo and end with the Co-Authored-By line).

Do not include tokens, the Apps Script `/exec` URL or personal training data in CLAUDE.md — the repo is public.
